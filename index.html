ABOUT THE MODEL

Predictive maintenance with machine learning

This educational prototype uses a Random Forest classifier trained on the AI4I 2020 predictive maintenance dataset. It uses product type, air temperature, process temperature, rotational speed, torque, and tool wear to estimate machine failure.

!
MODEL INTEGRITY

Use with appropriate caution

Failure events are comparatively rare. Review recall, precision, class balance, and real-world validation before using predictions to guide maintenance decisions.
